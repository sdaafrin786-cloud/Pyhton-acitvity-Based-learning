# Python Activity – Case Studies 1–10

## Project Overview

This project contains 10 Python case studies that demonstrate how programming can solve practical problems using input validation, conditional statements, loops, lists, sorting, calculations, and basic financial analysis.

## Case Studies

1. **University Scholarship Allocation** – Checks student eligibility using aggregate marks, subject marks, attendance, and family income, then ranks eligible students.
2. **Progressive Electricity Billing** – Calculates electricity bills using unit slabs, fixed charges, surcharges, and rebates, and flags unusual increases.
3. **Hospital Billing and Patient Classification** – Calculates patient bills, applies a senior-citizen concession, validates charges, and classifies patients by insurance status.
4. **Employee Payroll and Deduction Analysis** – Calculates gross salary, allowances, overtime, incentives, deductions, and net salary.
5. **Multi-Plan Telecommunications Cost Optimization** – Compares mobile plans, calculates extra usage charges, and selects the lowest-cost eligible plan.
6. **Railway Fare and Reservation Calculator** – Calculates passenger fares using distance, travel class, age-based concessions, and seat availability.
7. **Retail Billing with Multiple Discount Rules** – Creates an itemized bill using product categories, tax rates, and discount limits.
8. **Manufacturing Cost and Profitability Analysis** – Calculates production costs, revenue, profit, and whether a target profit percentage is achieved.
9. **Multi-Currency Travel Budget Analysis** – Converts travel expenses to INR, adds conversion fees, checks the budget, and identifies the largest expense category.
10. **Campus Event Financial Planning** – Calculates event costs, sponsorship shortfall, participant contribution, and minimum registrations needed to break even.

## Concepts Used

- Variables and user input
- Numeric calculations
- `if`, `elif`, and `else` conditions
- `for` loops
- Lists and dictionaries
- Sorting and ranking
- Input validation
- Percentage, discount, tax, and fee calculations
- Basic reporting and formatted output

## Requirements

- Python 3.x

No external libraries are required for the basic programs in this project. Case Study 10 uses Python's built-in `math` module.

## How to Run

1. Install Python 3.x.
2. Save the required case study code in a Python file, for example `case1.py`.
3. Open a terminal in the folder containing the file.
4. Run:

   ```bash
   python case1.py
   ```

   On some systems, use:

   ```bash
   python3 case1.py
   ```

5. Enter the values requested by the program and review the displayed results.

Replace `case1.py` with the filename for the case study you want to run.

## Notes

- The values and rules used in these case studies are assumptions for this academic activity.
- Railway fares, tax rates, discounts, and other sample rates are for the assignment and may not represent real-world rates.
- Enter valid values when prompted by each program.

## Learning Outcome

This activity provides practice in breaking real-world problems into steps and implementing the solutions in Python. It builds familiarity with decision-making, iteration, data handling, validation, and calculation-based programs.
